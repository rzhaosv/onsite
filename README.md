# Onsite: AI Lab Interview Prep

Structured preparation for the interview loops at Anthropic, OpenAI, Google DeepMind, Meta and Big Tech.

- **Loops** — round-by-round breakdowns compiled from public guides and candidate reports, with what each round tests and how to prepare. Chinese notes throughout.
- **Plan** — a week-by-week plan built backwards from your interview date and your own stated weak spots.
- **Mock** — an AI interviewer that runs a real round with follow-ups, then writes a debrief scorecard on the four-point scale (Strong Hire → No Hire) with dimensions, gaps and next drills.
- **Drill** — a question bank graded against what a strong answer covers, with spaced repetition.
- **Stories** — a STAR bank; the coach sharpens wording without inventing facts.

Independent, not affiliated with any company named. No offer is guaranteed.

- Expo SDK 57 / React Native 0.86 / TypeScript. No accounts; everything local.
- Backend: `tryforma.app/api/onsite` (Gemini proxy, lives in the forma repo).
- Billing: RevenueCat, entitlement `pro`, packages `$rc_weekly` (3-day trial) and `$rc_annual`.
- Web demos: `npx expo start --web`, then `?demo=welcome|today|loop|mock|scorecard|drill|drillgraded|stories|plan|me|paywall&snap=1`.
